# Front End - Angular Foro

# Exp2_S5_belen_guerrero
Actividad Sumativa 2: Desarrollando nuestro proyecto bajo lineamientos empresariales


## Tecnologías
- Angular
- TypeScript
- Bootstrap
- Spring Boot (API REST)
- JWT para autenticación

## Funcionalidades
- Inicio de sesión y registro de usuarios.
- Visualización de publicaciones.
- Consulta del detalle de cada publicación.
- Publicación de comentarios y respuestas.


## Ejecución local

Para ejecutar el proyecto en un entorno local:

**1. Instalar dependencias**

```bash
npm install
```

**2. Iniciar el servidor de desarrollo**

```bash
ng serve
```

**3. Acceder desde el navegador**

```text
http://localhost:4200
```

> Esta configuración corresponde únicamente a la ejecución local del proyecto.
